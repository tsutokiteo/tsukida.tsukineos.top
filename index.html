🌙 项目概述

TsukidaOS 是 TsukineOS 的孪生项目， 目标是构建一个 以 Java 和 JavaScript 为内核语言 的操作系统。 它不基于 Linux 内核，而是采用 AOT（预先编译） 技术， 将 Java/JS 代码直接编译为机器码，运行在裸机上。

项目将原生支持 x86_64 / x86（32-bit）/ ARM / ARM64 架构， 并内置 L2R2Java 翻译层，实现对 16-bit 实模式程序的兼容。

⚙️ 核心技术路线

AOT 编译 · 将 Java/JavaScript 源码预先编译为机器码，无需 JVM 或解释器

L2R2Java 翻译层 · 实现 16-bit 实模式 ↔ Java/JS 内核的双向调用

全架构支持 · 一份代码，多平台编译（x86/x86_64/ARM/ARM64）

Java 26 LTS JavaScript (ES2024) GraalVM Native Image C HAL (硬件抽象层)

🔗 与 TsukineOS 的关系

  • TsukidaOS 是 独立项目，不基于 TsukineOS 的代码。
  • 两者共享 统一的设计语言（配色、字体、交互理念）。
  • TsukidaOS 内部将集成 TKN-DOS 作为 16-bit 兼容层。
  • 护程序（OC 表情反馈）是 TsukineOS 的专属组件，不会出现在 TsukidaOS 中。
